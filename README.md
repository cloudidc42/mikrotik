## 🛠️ Prerequisites

### Software ที่ต้องการ
- **GNS3** หรือ **EVE-NG** สำหรับ Lab (แนะนำ)
- **VMware** หรือ **VirtualBox** สำหรับรัน RouterOS
- **Winbox** (Windows) หรือ browser-based WebFig
- **SSH Client** (PuTTY, Terminal, iTerm2)

### Hardware (ถ้าต้องการ)
- MikroTik RouterBoard ใดก็ได้ (hAP ac2, RB750Gr3, ฯลฯ)

### Programming Languages ที่ใช้
- **RouterOS Script** (ภาษา scripting ของ MikroTik)
- **PHP** (Web Backend)
- **Python 3** (Automation)
- **JavaScript/Node.js** (Web Frontend + Backend)
- **HTML/CSS** (Web Interface)
- **SQL** (Database)
